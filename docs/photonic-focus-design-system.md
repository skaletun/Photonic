# Photonic Focus · дизайн-система 2026

## Цель
Обычный человек должен понимать Photonic без знания интерполяции: открыть изображение → выбрать размер → скачать. Studio остаётся простым сценарием, Lab — средой сравнения алгоритмов. Технические функции не удаляются.

## Исследованные ориентиры
- Adobe Spectrum 2: адаптивные поверхности, дружелюбная геометрия, акцент у главных действий, независимые светлая/тёмная темы. https://spectrum.adobe.com/getting-started/introduction
- Fluent 2: четырёхпиксельный шаг отступов, ясная группировка пространством и адаптивная компоновка. https://fluent2.microsoft.design/layout
- Carbon: предсказуемые формы, минимум лишних решений и последовательная группировка настроек. https://www.carbondesignsystem.com/building-blocks/core/patterns/forms
- Apple HIG: адаптация под экран, безопасные зоны и размер текста. https://developer.apple.com/design/human-interface-guidelines/layout
- WCAG 2.2 (2.5.8): минимальная кликабельная область 24×24 CSS px либо достаточное расстояние. Основные действия у Photonic крупнее. https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum

Рекомендуемые отступы: 4 / 8 / 12 / 16 / 20 / 24 / 32 px. Радиусы: 6 / 10 / 14 / 18 / 24 px. IBM Plex Sans — текст и интерфейс, Instrument Serif — логотип и заголовок первого экрана.

Контраст акцента на основной панели не ниже 4.5:1 по выбранным токенам (около 5.77:1 для светлой темы). Это не сертификат WCAG: динамические состояния, фокус, читабельность и использование клавиатуры дополнительно проверяются отдельно.

## Правила
1. На первом экране выделяется одно главное действие — открытие фотографии. После загрузки — скачивание, а результат и текущий размер видны рядом.
2. Инспектор имеет визуальные шаги 01 «Новый размер», 02 «Метод», 03 «Экспорт». Быстрые размеры видны сразу; печать, пресеты, резкость и остальные параметры доступны ниже по иерархии.
3. Preview отделён от панелей. Цвет, контраст и геометрия изображения не меняются от темы приложения.
4. Превью большого изображения явно обозначается обзором; точные детали проверяются лупой 1:1.
5. Мобильный экран: сначала снимок, затем вкладки Размер / Метод / Экспорт; кнопка скачивания остаётся видимой.
6. Отчётливый focus-visible, кнопки с названиями, поля с label, ошибки не только цветом и понятные disabled-состояния обязательны.

## Компоненты
Mast — бренд, Studio/Lab, локальная обработка, открыть файл, язык, тема, помощь.
Preview — первый экран, три шага, образцы и просмотр.
Enlarger — инспектор размера/метода/экспорта и фиксированный footer.
DocumentQueue — активный файл, очередь и ошибки.
Help / Dialog — единая система отступов, заголовков, радиусов и фокуса.

## Файловая структура
- src/styles/tokens.css — палитра, типографика, spacing и radii.
- src/styles/focus.css — актуальный визуальный слой. Остальные CSS сохраняют геометрию редактора и canvas/gestures; Focus подключён последним в app/layout.tsx.
- src/lib/i18n/en.ts и ru.ts — ориентированные на задачу надписи.
- tests/browser/focus-design.spec.ts — основные UI-инварианты светлой и тёмной тем и mobile/desktop.

Проверка: npm run lint && npm run typecheck && npm test && npm run build && npm run test:browser.

Осознанное ограничение: синтетические тесты и эмуляторы браузера не заменяют ручную оценку восприятия на настоящих устройствах. Свой дизайн взят из принципов систем, а не скопирован из их компонентов.
