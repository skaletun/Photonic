# Photonic Studio

Локальное рабочее пространство для изменения размера изображений. Фотографии остаются на устройстве; нейросети и отправка файлов на сервер не используются.

[Открыть Photonic](https://skaletun.github.io/Photonic/) · [Исходники](https://github.com/skaletun/Photonic)

## Рабочее пространство

- **Studio:** большой холст, размер и метод в инспекторе, постоянно доступный экспорт, очередь с миниатюрами.
- **Lab:** сравнение двух методов, сетка из семи методов, график ядра и гистограмма. Лупа выбирает участок для последующего сравнения в сетке.
- На телефоне настройки разделены на вкладки **Размер / Метод / Экспорт**. Кнопка скачивания остаётся доступной.
- Светлая и тёмная темы, русский и английский языки, локальные шрифты.

Откройте файлы, перетащите их или вставьте изображение из буфера. Повторное добавление расширяет очередь. Файлы можно переставлять, удалять и экспортировать текущий, все в ZIP или по одному. Повреждённый файл получает статус ошибки; остальные продолжают обрабатываться. Ошибки можно повторить из очереди.

## Размер и экспорт

Размер задаётся в пикселях, процентах или через профили ½ / 1× / 2× / 4×. В дополнительных настройках доступны физический размер печати, миллиметры или дюймы и DPI. Собственные размеры и параметры сохраняются в именованные пресеты в этом браузере.

Экспорт: PNG, JPEG, WebP или формат исходника. GIF и BMP сохраняются в PNG; HEIC и AVIF — в JPEG. GIF открывается первым кадром. AVIF зависит от декодера браузера, HEIC использует нативный декодер или резервный wasm-декодер.

Для JPEG можно выбрать фон прозрачных областей. Предпросмотр сжатия показывает фрагмент до 512 px до и после кодирования с выбранным качеством; указанный там размер относится к фрагменту, а не всему файлу.

Результат получает профиль sRGB. Сведения о камере и авторстве можно сохранить или удалить; GPS не переносится. ZIP записывает UTF-8 имена и добавляет числовой суффикс при совпадении имён.

## Алгоритмы

По умолчанию используется **Photonic**: линейный свет, OKLab, сигмоида, Kaiser-sinc по светлоте, Mitchell по цветности, адаптивное ограничение ореолов и коррекция согласованности светлоты. Также доступны nearest, bilinear, bicubic, Lanczos, sinc (Hann) и B-spline.

Полный Photonic рассчитывается ограниченными полосами вместо шести массивов размером с выходной кадр. Сохранено побайтное совпадение с эталонными кадрами предыдущей версии. Лупа проходит ту же коррекцию, что и полный экспорт; резкость учитывает соседние пиксели за границей выбранного участка.

Полное превью используется до 8 Мп; для крупных результатов показываются обзор и лупа. Экспорт ограничен 120 Мп и стороной 16 384 px, а также консервативным бюджетом памяти устройства. Возможный размер зависит от исходника, выбранного метода и браузера. Если памяти недостаточно, приложение сообщает об этом до выделения выходных буферов.

## Горячие клавиши

| Действие                   | Клавиши                         |
| -------------------------- | ------------------------------- |
| Открыть файлы              | Ctrl/Cmd+O                      |
| Скачать текущий файл       | Ctrl/Cmd+S                      |
| Отменить настройки         | Ctrl/Cmd+Z                      |
| Повторить настройки        | Ctrl/Cmd+Y или Ctrl/Cmd+Shift+Z |
| Выбрать метод              | 1–7                             |
| Изменить масштаб просмотра | + / −                           |
| Временно показать исходник | Пробел                          |

Зум поддерживает колесо и щипок. Панорамирование — перетаскивание. Граница сравнения доступна с клавиатуры. Кнопки **По кадру** и **1:1** управляют масштабом просмотра.

## Офлайн и обновления

Photonic устанавливается как PWA. Оболочка, шрифты и сборочные ресурсы кэшируются для офлайн-запуска. Открытые с диска изображения в кэш оболочки не записываются. Android Share Target временно хранит переданный файл в отдельном inbox и удаляет его после чтения приложением.

Кэш получает версию при сборке. При появлении новой версии можно применить обновление кнопкой в заголовке; во время экспорта она заблокирована. Настройки и пресеты сохраняются в localStorage, изображения остаются в памяти до закрытия вкладки.

## Разработка

Требуется Node.js 20.9 или новее; CI использует Node.js 22.

```bash
npm ci
npm run dev
```

Локально: http://localhost:3000/

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

Для браузерных проверок:

```bash
npx playwright install --with-deps chromium firefox webkit
npm run build
npm run test:browser
```

GitHub Pages строится с `GITHUB_PAGES=true` и префиксом `/Photonic`. Проверки запускаются для веток и pull request; публикация main допускается после успешных тестов, проверки типов, ESLint, сборки и браузерных сценариев. Скриншоты и отчёт Playwright сохраняются в артефакте `browser-report`.

## Структура

| Модуль                          | Ответственность                                            |
| ------------------------------- | ---------------------------------------------------------- |
| `src/hooks/studio/useStudio.ts` | Состояние и подключения систем                             |
| `useDocuments.ts`               | Загрузка, очередь, статусы и жизненный цикл файлов         |
| `usePreviewPipeline.ts`         | Предпросмотр, сравнение, лупа и отмена устаревших расчётов |
| `useExports.ts`                 | Экспорт, пакетная обработка и восстановление исходника     |
| `useHistory.ts`                 | История настроек без удержания пиксельных буферов          |
| `src/components/preview/`       | Canvas и управление жестами                                |
| `src/components/inspector/`     | Размер, печать, резкость, формат и пресеты                 |
| `src/lib/resample/`             | Ядра, обработка полосами и протокол Worker                 |
| `src/lib/io/`                   | Декодирование, кодирование, EXIF, ICC и ZIP                |
